# Тестовый аддон с модулями

Аддон с TypeScript- и Rust/WASM-модулями. Локально работает без публикации.

## Запуск

Нужны Node.js 20.19+ в ветке 20.x либо 22.12+, Yarn, Rust с Cargo и актуальные PulseSync и мод. Один раз выполните:

```bash
rustup target add wasm32-unknown-unknown
```

Войдите в PulseSync, откройте Яндекс Музыку и выполните из этой папки:

```bash
yarn install
yarn dev
```

Изменения подхватываются автоматически. Остановить: Ctrl+C.

Кнопка «Случайный трек · WASM» включает другой трек из очереди, выбранный Rust-модулем. Добавьте в очередь хотя бы два трека.

## Где код

```text
modules/typescript/index.ts     (TypeScript)
modules/rust/src/lib.rs         (Rust)
modules/rust/Cargo.toml         (сборка Rust)
src/module-demo.ts             (вызовы модулей)
```

Для нового модуля добавьте папку в `modules/` с `index.ts`, `index.js` или Rust-проектом, как в примере. Имя папки используется в SDK.

По умолчанию API 1. Другой номер задаётся в `module.json`: `{ "apiMajor": 2 }`, у TS/JS также в `defineModule`.

## Команды

- `yarn dev`: разработка с автообновлением.
- `yarn build:sync`: собрать и установить всё.
- `yarn build:modules`: собрать модули в `dist/modules/`.
- `yarn sync`: собрать модули и установить готовый аддон.

После перезапуска PulseSync локальный режим включит работающий `yarn dev` или команда `yarn sync`.

## Проверка через каталог

Модули не входят в архив аддона. Для проверки публикации:

1. Загрузите файлы из `dist/modules/` в кабинет и опубликуйте после модерации.
2. Укажите свои `moduleIds` в `addon.config.mjs`, соберите и опубликуйте аддон.
3. Запустите `yarn serve:modules` и установите аддон из каталога.

Сервер `127.0.0.1:4174` доступен только вам. Для других пользователей укажите свой сервер в `moduleBaseUrl`.
